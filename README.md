# 🃏 Memory Card Matching Game (Level Progression Edition)

A sleek, modern, and fully responsive **Memory Card Matching Game** built with pure **HTML5, CSS3, and JavaScript (Vanilla JS)**. 

The game features an interactive **Mode Selection (Easy, Medium, Hard)** system paired with a **Win-to-Unlock 5-Level Progression Engine**. Players must clear each level within the dynamic countdown timer to advance to the next level!

---

## 🔥 Key Features

- 🎯 **Mode Selection:** Select from **Easy**, **Medium**, or **Hard** modes right from the interface.
- 🔓 **Win-to-Unlock Progression:** Start at **Level 1** and unlock up to **Level 5**. You must win the current level to proceed.
- ⏳ **Automated Countdown Timers:** Times automatically scale and decrease as you progress through higher levels.
- 📐 **Dynamic Responsive Board:** CSS Grid layout automatically adapts card count (8 to 24 cards) based on the active level.
- 🎨 **Modern Dark UI:** Glassmorphism styling with smooth 3D CSS card-flip animations.
- 📊 **Real-time Stats:** Live tracking for remaining time, total moves, and dynamic score calculation.
- 🏆 **Interactive End Game Modal:** Custom win/lose modal alerts with options to retry or jump to the next level upon winning.

---

## 🎮 Game Progression & Level Rules

### 🕹️ Modes Overview
| Level | Cards Count | Grid Layout | Easy Time | Medium Time | Hard Time |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **Level 1** | 8 Cards (4 Pairs) | 4 x 2 | 3.5 Mins | 3.0 Mins | 2.5 Mins |
| **Level 2** | 12 Cards (6 Pairs) | 4 x 3 | 3.0 Mins | 2.5 Mins | 2.0 Mins |
| **Level 3** | 16 Cards (8 Pairs) | 4 x 4 | 2.5 Mins | 2.0 Mins | 1.5 Mins |
| **Level 4** | 20 Cards (10 Pairs) | 5 x 4 | 2.0 Mins | 1.5 Mins | 1.0 Min |
| **Level 5** | 24 Cards (12 Pairs) | 6 x 4 | 1.5 Mins | 1.0 Min | 0.5 Min |
