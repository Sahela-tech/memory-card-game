# 🃏 Memory Card Matching Game (Level Progression)

A sleek, modern, and responsive **Memory Card Matching Game** with progressive level unlocking!

## 🎮 Game Rules & Modes
* **Select Mode:** Choose between **Easy**, **Medium**, or **Hard**.
* **Progressive Unlocking:** You start at **Level 1**. Win the current level before time runs out to unlock the next level up to **Level 5**!
* **Auto Time Adjustments:** Times automatically decrease as levels increase.

## 🛠️ Built With
* **HTML5 & CSS3:** Responsive grid layout, flexbox, smooth 3D transforms.
* **JavaScript (ES6):** Dynamic level engine & countdown mechanics.

## 💻 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in your browser.
